## Isolated VU arithmetic probe

Added host-only `ps2vu_math_probe mul|madd LHS RHS ACC [EXPECTED]`. All operands
are exactly eight raw hexadecimal digits. It initializes VF1/VF2/ACC identically
in all lanes, executes one lower-NOP/upper-arithmetic pair, and reports the
opcode, results, MAC, PC, pair count and modeled cycles. MUL is vector MUL;
MADD uses broadcast-x with identical RHS lanes. Source registers and ACC must
remain unchanged. This intentionally excludes dependencies and Q latency.

Example: `./build-release/ps2vu_math_probe madd 40000000 40400000 3F800000 40E00000`
checks exactly representable2*3+1=7. No expected argument means observation only,
not correctness certification. Exit2 rejects malformed input; exit3 reports a
result mismatch; exit1 indicates an execution/invariant failure.

Tests cover exact MUL/MADD, malformed hex, and a deliberately wrong expected
result. No PS2 edge-case expectations fabricated from native host floats. This
is comparison infrastructure, not the independent reference adapter yet. User
confirmed no contact with the developer; only inspect his work and stay focused
on the intro. No emulation arithmetic or timing changed in this checkpoint.
