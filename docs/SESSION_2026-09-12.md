## Coworker recommendation: first bounded causal-debugger slice

Implemented the first portion of the user's recommended causal debugger rather
than adding another independent store log. Optional `enable_causal_trace(true)`
records lane-level immutable nodes for supported upper VF/ACC writes, lower VF
inputs, and SQ/SQI memory stores. Store nodes include instruction, PC, pair,
modeled cycle, address, source VF/lane and mask. Parent IDs link through upper
arithmetic and ACC dependencies. IDs increase within a trace epoch; zero denotes
unknown. Per-word memory roots preserve masked-lane ownership. Rejection freezes
the four root IDs for that qword before later writes can replace them.

Same-pair stores use pre-upper producer IDs, matching their value snapshots.
VIF UNPACK invalidates overwritten memory ownership. Other external writers must
call the invalidation API; arbitrary direct Memory/state mutation is not globally
observed. The first stage deliberately stops at lower-load/MFIR input nodes,
initial state and Q dependencies. It does not yet slice VIF inputs, VI/address
calculations, branches, MAC/status or the complete control dependence graph.
`incomplete` marks missing direct inputs; ancestors can independently be incomplete.
ACC nodes have an explicit accumulator flag, not an ambiguous VF0 interpretation.

The graph holds at most 8,192 nodes, reports dropped nodes, and never reuses live
IDs after truncation. The replay walks at most 64 distinct nodes backward from
the rejected tag, reporting a traversal limit if reached. Reset and changing
trace enable state clear the graph. It is off by default.

Local `build-release/causal-first.txt/.ppm`: 2,904 nodes, zero dropped, unchanged
998 pairs / 1308 cycles / PATH1 8/1. Automatically recovered x-lane chain:

`tag word at 0160 -> store node 61 (SQI, PC 06A8, pair 17, VF12.x)
-> node 37 (MADDw, PC 0688, pair 13) -> VF inputs and earlier ACC producers`.

The value remains 420F028B throughout the final producer/store edge. Earlier

Tests cover a synthetic ADD -> FTOI -> SQI -> rejected-tag walk, unknown leaves,
