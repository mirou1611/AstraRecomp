replay stores all 368,640 bytes. TEX0 context state, UV coordinates, nearest

textured sprites. Focused tests validate split DMA traversal, 2D local-memory
row stride, and an end-to-end four-color textured sprite.

The replay remains at framebuffer hash `AE6BFFA9F3064B83` with `0/17920`
nonzero pixels. This boundary contains two genuine untextured sprites and no

## Resumed correctness audit

- PACKED RGBA stores its channels in four separate 32-bit slots. PACKED UV
  and XYZ2 likewise differ from A+D/REGLIST layouts. Decode these explicitly;
  reconstruct Z from the upper qword and honor XYZ2 ADC draw suppression.
  Correct the old texture fixture and use asymmetric coordinates, channel
  values, padding, and depth to catch the former shared assumption.
- Apply PRE only to nonempty PACKED tags.
- VU IADDIU/ISUBIU use unsigned 15-bit immediates. Sign extension changed the
  captured `0x7FFF` mask to `0xFFFF`, leaving the `0x8000` flag in the BIOS
  loop counter. The captured mask sequence now reduces `0x8004` to `4`.
  The former six-million-pair completion is invalid evidence of a correct VU
  workload. Keep the execution ceiling solely as a defensive limit.
- The 4 MiB backing store remains a simplified linear model. Hardware GS
  swizzling, overlapping format views, multi-IMAGE transfer cursor persistence,
  independent GIF path state/arbitration, and more VU pipeline semantics remain
  open issues. Texture round-trip tests do not validate those properties.
- VIF currently treats an unsupported VU instruction (running becomes false)
  like a clean microprogram stop. A follow-up should distinguish those outcomes
  before accepting later VIF commands; a zero VIF rejection count alone is not
  a reliable correctness gate.

## Follow-up: XYZF decoding and transfer/error handling

PACKED XYZF2/XYZF3 now extract X/Y and 24-bit Z with their own layout and
respect ADC/non-drawing writes. A+D/REGLIST XYZF2/XYZF3 and XYZ3 also reach
vertex assembly with the correct drawing intent. Fog is not yet applied, and
STQ/perspective texture rendering remains unimplemented; any newly emitted
geometry is still a partial reference rendering, not a validated BIOS intro.

VIF MSCAL/MSCNT now rejects the current submission on an unsupported VU
instruction instead of treating it as a successful stop and executing trailing
UNPACK commands. Tests verify the later VU data memory remains untouched.

The logical IMAGE transfer cursor now persists across IMAGE tags until TRXDIR
restarts it. Tests cover two tags filling different rows, excess data after
rectangle completion, and an explicit restart. This does not change the known
linear-memory/swizzle limitation.

Sprite UV interpolation now retains the original endpoint coordinates through
scissor clipping instead of stretching the remaining texture over the clipped
rectangle. A four-texel fixture clipped to its last two pixels verifies this.

The XYZF/VIF-error-handling BIOS replay (`build-release/xyzf-2488m.txt`) remains
at 971 VU pairs, 36 GIF submissions, 2 sprites, 0 triangles and the black hash.
The final tag is PRE=1, PRIM=0x5C (textured/fogged triangle strip), NLOOP=4.
All four captured XYZF vertices have ADC set (upper word `FFFF8000`), and the
four RGBA payloads are zero. This explains draw suppression in that captured
packet; investigate the VU math/flags generating it and the outstanding XGKICK
rejection. Do not bypass ADC to manufacture visible output. This replay
preceded the separately regression-tested IMAGE cursor and sprite clipping fixes.
