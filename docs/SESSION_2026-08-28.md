## PS2Recomp evaluation

Upstream: <https://github.com/ran-j/PS2Recomp>

Inspected commit: `14b1e5cb39b4af7e6fc12f9a29fdc751efde49d7`

PS2Recomp is a strong Phase-0 frontend because it already provides ELF and
relocation analysis, R5900-to-C++ emission, direct-call binding, indirect-call
fallback, fast RAM paths, MMI/VU0 helpers, HLE hooks, and IOP profiles.

It is not the final Rev8 backend:

- generated functions repeatedly materialize `R5900Context`; there is no
  SSA/liveness/register-allocation layer;
- no complete SNR2/overlay activation architecture was found;
- the supplied Vita renderer uses raylib, SDL2, GL translation, and PVR rather
  than the blueprint's direct native GXM/title-specialized renderer;
- the project is GPLv3, while the current AstraRecomp source is MIT. Upstream
  code must remain separated until the combined-project licensing decision is
  explicit.

Decision: use PS2Recomp's analyzer/emitter as a bootstrap tool and adapt its
generated functions to a small AstraRT ABI. Do not adopt its full runtime as
the long-term Vita architecture.
