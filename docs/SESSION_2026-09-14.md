## Follow-up: GIF texture attribute latches

Implemented the missing PACKED STQ handler. ST is written immediately; Q goes
to a separate temporary latch and is copied into RGBAQ only by PACKED RGBA.
Each nonempty processed GIFtag resets temporary Q to the raw float-one bits.
A+D and REGLIST ST leave RGBAQ.Q alone. XYZ now snapshots raw ST, UV and Q in
GsVertex, preserving attributes through existing list/strip/fan assembly.

Reference checked: PCSX2 v2.4.0 GSState.cpp, GIFPackedRegHandlerSTQ,
GIFPackedRegHandlerRGBA, GIFRegHandlerST and Transfer tag initialization:
https://raw.githubusercontent.com/PCSX2/pcsx2/v2.4.0/pcsx2/GS/GSState.cpp
This implementation retains raw bits; it deliberately does not copy reference
renderer zero/NaN substitutions as if they were verified hardware behavior.

Fixtures cover split input, STQ without RGBA retaining the earlier Q, explicit
A+D RGBAQ, per-vertex latching, new-tag temporary-Q reset, REGLIST ST/UV and
reset. Release CTest 2/2 and UBSan CTest 2/2 pass; Vita VPK builds. The first-VIF
replay still exits at the known rejected PATH1 tag (local stq-latch-first.txt).
No new 800M replay was performed for this state-only change.

This does NOT implement texture sampling for triangles or establish a visible
intro improvement. Next: use these latched attributes in a tested textured
triangle raster path, checking texture format/addressing coverage before a long
BIOS visual comparison. Audio remains paused.

## Follow-up: fixed-UV textured triangles

GIF triangles with TME=1 and FST=1 now call the existing logical-local-memory
texture sampler for covered fragments. The GS rasterizer interpolates raw 10.4
UV before truncating to texel coordinates, keeps attributes attached when winding
is reversed, and sends sampled color through existing alpha/depth/blend output.
Untextured triangles retain their old path. This is an affine, nearest-sample
implementation, not the perspective ST/Q path.

The rendering-stage validation approach was guided by the 3d-games skill; the
PS2 reference inspected was PCSX2 v2.4.0 GSDrawScanline.cpp CSetupPrim, which
distinguishes fixed UV from interpolated STQ:
https://raw.githubusercontent.com/PCSX2/pcsx2/v2.4.0/pcsx2/GS/Renderers/SW/GSDrawScanline.cpp
Independent fixtures upload a four-color 2x2 texture and draw two triangles in
both windings and both GS contexts. Tests check shared-edge coverage, fractional
UV interpolation and alpha-test rejection after sampling.
Validation: Release CTest 2/2, UBSan CTest 2/2, and Vita VPK build pass.

Limitations inherited from the sampler remain: logical linear PSMCT32/16 memory,
no GS swizzle/CLUT, no CLAMP modes or filtering, incomplete TFX/TCC/TEXA semantics.
ST/Q triangles still use the untextured path. No BIOS visual improvement is
claimed and no new long BIOS replay was run. Next implement and test perspective
ST/Q plus safe nonfinite handling, then inspect actual BIOS texture state and
compare captured output. Do not mistake passing synthetic fixtures for an intro.
