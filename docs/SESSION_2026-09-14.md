## Follow-up: GIF texture attribute latches

Implemented the missing PACKED STQ handler. ST is written immediately; Q goes
to a separate temporary latch and is copied into RGBAQ only by PACKED RGBA.
Each nonempty processed GIFtag resets temporary Q to the raw float-one bits.
A+D and REGLIST ST leave RGBAQ.Q alone. XYZ now snapshots raw ST, UV and Q in
GsVertex, preserving attributes through existing list/strip/fan assembly.

Reference checked: PCSX2 v2.4.0 GSState.cpp, GIFPackedRegHandlerSTQ,
GIFPackedRegHandlerRGBA, GIFRegHandlerST and Transfer tag initialization:
https://raw.githubusercontent.com/PCSX2/pcsx2/v2.4.0/pcsx2/GS/GSState.cpp
This implementation retains raw bits; it deliberately does not copy reference
renderer zero/NaN substitutions as if they were verified hardware behavior.
