## Rejected-tag ancestry guard

Fixed a diagnostic correctness gap: rejected-tag snapshots previously copied
memory ownership IDs without checking that those owners still matched the bytes
read by XGKICK. A direct external write bypassing the invalidation API could
therefore produce a false causal explanation. Each lane now compares its owner
value with the actual consumed qword before freezing the root; a mismatch clears
that lane's ownership. Unchanged lanes retain their links. Same-value unobserved
writes remain undetectable without a universal write observer.
