# Visual asset provenance

The PNG files in this directory are original project artwork generated for
AstraRecomp with OpenAI's built-in image generation tool on 2026-08-30. They are
decorative conceptual art, not screenshots, compatibility evidence, or images of
commercial hardware.

## Prompts

`astra-hero.png` requested a wide GitHub hero showing abstract instruction blocks
passing through a crystalline translation core into a subtle handheld-screen
frame. It specified the AstraRecomp indigo/cyan/violet palette and prohibited
text, logos, trademarks, PlayStation symbols, recognizable hardware, fake
gameplay, and watermarks.

`astra-architecture.png` requested a panoramic engineering visualization of two
synchronized processing nodes exchanging packet capsules through deterministic
timing arcs, with distant framebuffer layers. It used the same palette and the
same trademark, hardware, text, fake-UI, and watermark exclusions.

See [the visual system](../BRAND.md) for palette, typography, accessibility, and
usage guidance.
